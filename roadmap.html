03
Motor Control · 4-Layer PCB · THE showstopper
FOC Motor Controller from Scratch

Field-Oriented Control, implemented from scratch in C — no SimpleFOC, no ST motor control library. Custom 4-layer PCB: STM32G4 (math-optimized core) + DRV8353 gate driver + INA240 inline current sensing + magnetic encoder interface (AS5047P). Clarke transform → Park transform → SVPWM → PI current loops. Plot your loop bandwidth on a Bode plot.

What you'll learn
4-layer stackup design. High-side gate drive. Inline current sensing layout. Real-time control loop tuning. Power planes and EMC basics.
Opens doors at
Tesla (motor team) Rivian Boston Dynamics Figure AI Sarcomere (senior) Any servo drive co.
↑ This is the project that makes a senior engineer lean forward in an interview. Undergrads don't build this. This is the line.

04
Power Electronics · Automotive · Safety
4S LiPo BMS with CAN Bus

Custom PCB around BQ76920 or ISL94202: 4-cell monitoring, passive cell balancing, OV/UV/OC/OT protection, NTC thermistor integration. STM32 firmware handles Coulomb counting + OCV-based SoC estimation. CAN bus (ISO 11898) interface — because that's how automotive talks. This is the kind of work that appears on job descriptions at every EV company.

What you'll learn
Cell chemistry fundamentals. Protection circuit design. SoC estimation algorithms. CAN bus implementation. Regulatory safety thinking.

05
System Integration · Precision Mechanics
Desktop PCB Milling Machine

AMB 800 FME spindle, 2020 extrusion frame, custom motion controller (improved stepper driver board from P1 learnings). Z-probe for surface height mapping, vacuum table for workholding. Target: 8 mil trace / 8 mil space on real FR4. The actual deliverable isn't the machine — it's the PCB you mill with it. Closes the loop on hardware ownership: you now manufacture your own boards.

What you'll learn
Spindle RPM control. Surface probing algorithms. Toolpath generation. Mechanical rigidity vs. cost tradeoffs. End-to-end manufacturing.
Why it's here
Every project after this gets faster and cheaper. You iterate on hardware in hours, not days. The machine pays for itself by project 8.

06
Digital Design · RTL · FPGA
Custom FPGA Board + RTL Implementation

Don't buy an Arty or an iCEBreaker — design the board. Custom ECP5 or iCE40 PCB with SRAM, UART interface, and JTAG programming. Then implement something non-trivial in RTL: a CORDIC engine (you'll use this in your FOC controller for sin/cos), or a custom SPI/I2C peripheral, or a pipeline that processes encoder data. The goal is to show you understand digital logic at the gate level.

What you'll learn
FPGA bring-up and configuration. SystemVerilog/VHDL synthesis. Timing constraints and static timing analysis. High-speed signal integrity basics.
Opens doors at
AMD / Xilinx NVIDIA (digital HW) Intel Qualcomm FPGA-heavy robotics

07
High-Speed Layout · Embedded Linux
Compute Module Carrier Board + Linux Driver

Design a carrier board for the Raspberry Pi CM4 (or equivalent). Include USB 3.0, PCIe, MIPI CSI camera, HDMI, and a custom peripheral (e.g., your BLE sensor node from P2 via UART or SPI). Boot a custom Yocto or Buildroot image. Write a kernel driver for the peripheral. This is high-speed PCB layout territory — DDR4 routing rules, impedance control, eye diagram validation.

What you'll learn
High-speed layout (USB 3, PCIe, DDR). Controlled impedance. Yocto/Buildroot. Linux kernel driver structure. Device tree overlays.

08
Robotics · Actuator Hardware
Closed-Loop Robotic Joint Module

Take your FOC controller (P3), miniaturize it onto a compact form-factor PCB colocated with a BLDC + AS5047P absolute encoder. Add a CAN or EtherCAT interface. Write a ROS2 node that treats this as a standard joint. Characterize it properly: torque constant, backdrivability, current loop bandwidth. This is not "I hooked up a motor" — this is "I designed a joint module with a datasheet."

What you'll learn
Miniaturization constraints. Thermal management. EtherCAT or CAN FD protocol. ROS2 hardware interface. Actuator characterization methodology.
Opens doors at
Boston Dynamics Figure AI 1X Technologies Sarcomere (senior) Any humanoid startup

09
Mixed-Signal · Analog Design
Precision Impedance Analyzer / Lock-in Instrument

Build a precision mixed-signal instrument: an impedance spectrometer or lock-in amplifier. Custom PCB with a 24-bit ADC (ADS1256 or AD7124), precision voltage reference, DDS signal source (AD9833), and instrumentation amplifier front-end. Proper analog layout — ground splits, shielding, star grounding. Firmware handles FFT, phase extraction, USB streaming to a Python GUI. Measure something real: a capacitor, a battery's internal impedance, a sensor's response.

What you'll learn
Analog layout and noise floors. Instrumentation amp selection. Signal chain design. DSP in firmware. The difference between a µV and a mV matter.
